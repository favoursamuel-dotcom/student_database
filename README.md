# Student Database CLI (Python)

## Overview

The **Student Database CLI** is a command-line application built in Python as part of my journey to becoming a software developer and AI engineer. It allows users to manage student records through a simple interactive menu while practicing core Python programming concepts.

This project focuses on learning problem-solving, data structures, and CRUD (Create, Read, Update, Delete) operations without relying on external libraries or databases.

---

## Features

Current features include:

* ➕ Add a new student
* 📋 Display all students
* 🔍 Search for a student by ID
* ✏️ Update a student's score
* 🗑️ Delete a student
* 🎓 Automatically calculate a student's grade from their score
* 🚪 Exit the application

Each student record contains:

* Student ID
* Name
* Age
* Score
* Grade

## How to Run

1. Clone the repository.

```bash

```

2. Navigate into the project folder.

```bash
cd student_database
```

3. Run the application.

```bash
python student_db.py
```
